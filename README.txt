RAJA CHAMUNDA MANDAP SERVICE WEBSITE
====================================

Files:
- index.html      Home page
- about.html      About page
- services.html   Services page
- gallery.html    Gallery page
- contact.html    Contact page
- style.css       Shared styling for all pages
- script.js       Shared navigation menu script

How to use:
1. Keep all files in the same folder.
2. Open index.html in a browser to view the website.
3. Upload the complete folder contents to your web hosting to publish it.

Notes:
- The gallery currently uses sample online photos.
- Add your WhatsApp number in contact.html before enabling a WhatsApp booking link.
